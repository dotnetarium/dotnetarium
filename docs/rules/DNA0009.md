# DNA0009: Hard-coded secrets in code

CWE-798. C# code supplies a literal password or cryptographic key to a modeled security-sensitive API.

**Fix:** Retrieve secrets from a managed secret store or deployment configuration. Rotate credentials that may have been exposed. Use obvious placeholders for fixtures.

**Scope:** Includes credential APIs and selected .NET, Bouncy Castle, NSec and Sodium key APIs. Literal byte arrays and zero-filled keys are covered. Variable names alone are not evidence; a reported literal may be a deliberate test vector.

[DNA0022](DNA0022.md) instead checks recognizable provider credentials in configuration files, without requiring code usage.

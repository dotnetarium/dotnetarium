# DNA0021: XML external entity resolution

CWE-611. Untrusted XML reaches a parser explicitly configured for unrestricted external resolution. It may read local files or contact remote services.

**Fix:** Prohibit DTDs and leave `XmlResolver` null. If external resources are required, use a restricted resolver.

**Scope:** Checks modeled `XmlReader`, `XmlDocument` and `XmlTextReader` operations. Requires an explicit `XmlUrlResolver`; readers also require `DtdProcessing.Parse`. Modern defaults, null/restricted resolvers and ambiguous settings are excluded. Entity-expansion denial of service is outside this rule.

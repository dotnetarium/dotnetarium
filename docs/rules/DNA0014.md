# DNA0014: ECB mode use

Electronic Codebook (ECB) encrypts identical plaintext blocks to identical ciphertext blocks under the same key. Repeated structure remains visible in the encrypted data, so using a strong cipher such as AES does not make ECB appropriate for general message encryption.

## Recommendation

Use authenticated encryption, such as `AesGcm`, for new data. The stored or transmitted format must include the nonce and authentication tag needed by the receiver. Simply changing an ECB setting to CBC does not provide message authentication.

The rule reports `EncryptEcb`, ECB mode assignments, supported Bouncy Castle selections and Godot AES ECB encryption. An explicit encryption call is evidence of encryption; a mode assignment or cipher selection can also belong to a legacy decryption path. Review that distinction before changing an existing data format.

If ECB is required only to read old data, isolate that compatibility code and avoid using it for new writes.

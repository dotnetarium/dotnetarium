# DNA0024: Unrestricted credentialed CORS

CWE-942. An applied ASP.NET Core CORS policy accepts every origin and allows credentials. An untrusted site may read authenticated responses when the browser sends credentials.

**Fix:** Replace the accept-all predicate with `WithOrigins` listing trusted origins. Allow credentials only when required.

**Scope:** Requires an applied policy with an always-true `SetIsOriginAllowed` predicate and `AllowCredentials`. Unused policies and public APIs without credentials are excluded. The finding does not prove browser credentials are sent or sensitive data is exposed.

# DNA0011: Server-side request forgery

CWE-918. Untrusted data selects an outbound request destination and may let an attacker reach services available to the server.

**Fix:** Restrict destinations to trusted hosts and schemes. Enforce address and redirect restrictions when requests are made; a fixed `BaseAddress` alone does not prevent absolute URLs from overriding it.

**Scope:** Includes modeled HTTP and gRPC destinations and tracked `BaseAddress`/`RequestUri` state. Server-side Blazor navigation URLs can be sources. Some URI/channel construction sites are reported before a request is proven to occur.

See [recognized destination validation and limits](../taint-validation.md).

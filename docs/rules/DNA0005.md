# DNA0005: Open redirect

A redirect destination taken from a request can send a user to an attacker-controlled site. This is often used to make a phishing link appear to belong to the application, including links that return from authentication.

## Recommendation

Use `LocalRedirect` when the destination must stay within the application. If external destinations are required, restrict them to an explicit set of trusted sites. Check the same value that is later used, without changing it between validation and redirection.

## Example

An unrestricted return URL can redirect outside the application:

```csharp
return Redirect(returnUrl);
```

For a local return URL, use the framework's validation and a fixed fallback:

```csharp
if (!Url.IsLocalUrl(returnUrl))
    return LocalRedirect("/");

return LocalRedirect(returnUrl);
```

Authentication return destinations are reported at `AuthenticationProperties.RedirectUri` assignment. For those findings, review where the value is consumed; the rule does not reconstruct every external-provider callback.

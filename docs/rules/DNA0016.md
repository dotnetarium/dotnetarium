# DNA0016: Low PBKDF2 work factor

CWE-916. An explicit PBKDF2 iteration count below 100,000 makes password guessing cheaper.

**Fix:** Select a work factor appropriate to the hash algorithm and deployment. The detection cutoff is not a recommended secure setting; follow [password-storage guidance](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html).

**Scope:** Checks constant counts in .NET PBKDF2 APIs, ASP.NET Core `KeyDerivation.Pbkdf2` and `PasswordHasherOptions.IterationCount`. Runtime counts are not evaluated.

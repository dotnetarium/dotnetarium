# DNA0004: Untrusted file path

CWE-22. Untrusted data selects a path used for file access, archive extraction or code loading. It may access files outside the intended directory.

**Fix:** Resolve paths against a trusted root and verify canonical containment before access. Apply the same check to each directly extracted archive entry. Restrict code-loading paths to trusted files.

**Scope:** Reports reads, writes, deletion, copy/move/replace, extraction, physical-file responses and path-based assembly/native-library loading. Object construction, metadata checks, listing and standalone directory creation are excluded. A finding does not prove root escape or missing authorization.

See [recognized path validation and limits](../taint-validation.md).

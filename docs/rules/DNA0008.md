# DNA0008: Risky Json.NET polymorphism setting

CWE-502. A non-`None` `TypeNameHandling` setting lets JSON select .NET types. Deserializing untrusted JSON with unrestricted types can be dangerous.

**Fix:** Keep `TypeNameHandling.None`. If polymorphism is required, restrict permitted types with a reviewed serialization binder.

**Scope:** Reports constant settings, without proving that untrusted JSON is later deserialized. Ordinary `System.Text.Json` deserialization is not a sink for this rule.

# DNA0005: Open redirect

CWE-601. Untrusted data selects a redirect destination and may send users to an attacker-controlled site.

**Fix:** Use `LocalRedirect` for local destinations. Otherwise, allow only trusted destinations. An `IsLocalUrl` check must guard the same unchanged value used by the redirect.

**Scope:** Includes MVC, Razor Pages, HTTP response and Minimal API redirects. Authentication return URLs are checked at `AuthenticationProperties.RedirectUri` assignment; the rule does not prove later callback consumption.

See [recognized destination validation and limits](../taint-validation.md).

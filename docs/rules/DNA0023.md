# DNA0023: Unsafe BinaryFormatter deserialization

CWE-502. Untrusted data reaches `BinaryFormatter.Deserialize` with an explicit reference to the unsupported compatibility package that restores its unsafe implementation.

**Fix:** Migrate to `System.Text.Json` with a fixed application data schema. A serialization binder does not make `BinaryFormatter` safe for untrusted input.

**Scope:** Requires modeled byte/stream provenance and the compatibility-package reference. The in-box .NET 10 implementation throws; an old project flag alone is not reported.

See the [migration guide](https://learn.microsoft.com/en-us/dotnet/standard/serialization/binaryformatter-migration-guide).

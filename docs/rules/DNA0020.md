# DNA0020: TLS certificate validation bypass

CWE-295. A callback installed on a modeled networking API accepts every certificate. TLS then fails to authenticate the remote peer.

**Fix:** Remove the bypass and retain platform certificate validation. Trust the appropriate development certificate instead of accepting every certificate.

**Scope:** Covers HTTP, WebSocket and TLS validation callbacks proven to return `true`. Partial or unknown validators are not reported. Recognized development/non-production guards, DEBUG-only configuration and test projects are excluded; these exclusions do not prove a deployment is safe.

See [development exceptions and test configuration](../tls-certificates.md).

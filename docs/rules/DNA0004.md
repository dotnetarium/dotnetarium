# DNA0004: Untrusted file path

CWE-22. Untrusted data reaches a file path, including an archive extraction destination. This does not prove that the path escapes an allowed root; applications may intentionally let users select files. Resolve sensitive paths against a trusted root and verify that the canonical result remains under it. `Assembly.LoadFile` and `LoadFrom` additionally deserve review as code-loading paths.

This rule reports a candidate that needs review in the application's trust context. Configure severity with `dotnet_diagnostic.DNA0004.severity` in `.editorconfig`.

Recognized canonical root checks and their limits are documented in
[validation precision](../taint-validation.md).

Combining a constant root with an unchanged filename is also recognized when
consuming guards reject `..` and all path delimiters, including Windows `:`.
`IndexOfAny(Path.GetInvalidFileNameChars()) >= 0` can supply the delimiter check.
Separator-only checks are incomplete on Windows: `C:filename` is drive-relative
and discards the earlier root in `Path.Combine`. `GetFileName` and `GetFullPath`
alone are not blanket sanitizers, and validating a leaf does not validate a
separately supplied untrusted root.

Basename extraction followed by a consumed constant alphanumeric prefix/suffix
check (for example `log-` or `.txt`) is recognized when combined with a constant
or trusted application configuration root. This excludes `..` and removes
platform path separators. It establishes lexical root containment, not permission
to read every matching file, protection from symlinks, or a ban on Windows alternate
data streams. Ignored checks and reassigned values remain reportable.

SharpCompress `IEntry.Key` is an archive-path source, independent of transport
scope. Direct `WriteToFile`/`WriteToFileAsync`, reader `WriteEntryToFile` and
string/FileInfo file-writing overloads are modeled where they accept destinations.
For example, checking `Files/` and removing that prefix still permits
`Files/../outside/file`; canonicalize and check containment before direct writes.
The library's directory-extraction helpers apply containment to entry paths and
are negative controls when the destination root is trusted. Archive keys are
not added as blanket HTML/SQL sources.

# DNA0019: gRPC call credentials over plaintext

CWE-319. A gRPC channel is configured to send call credentials over unencrypted HTTP.

**Fix:** Use an HTTPS endpoint with certificate validation. Remove `UnsafeUseInsecureChannelCallCredentials` outside deliberate local tests.

**Scope:** Requires a constant remote `http://` address, inline channel options, explicit insecure-call-credential opt-in and supplied call credentials in `GrpcChannel.ForAddress`. Loopback addresses are excluded. Runtime addresses and options stored in variables are not inferred.

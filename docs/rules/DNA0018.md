# DNA0018: Detailed gRPC errors enabled

CWE-209. A gRPC service registration enables detailed errors, which can disclose exception information to clients.

**Fix:** Leave detailed errors disabled in production. Return controlled errors and keep exception details in server-side logs.

**Scope:** Reports unconditional `EnableDetailedErrors = true` registrations. Conditionally guarded registrations are skipped; runtime configuration is not evaluated.

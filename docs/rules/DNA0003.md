# DNA0003: Cross-site scripting

CWE-79. Untrusted data reaches HTML or markup output. Let Razor or Blazor encode ordinary text and use a context-aware encoder before deliberate raw markup.

Raw sinks include `HtmlString`, `IHtmlHelper.Raw`, `IHtmlContentBuilder.AppendHtml`, and Blazor markup rendering. `HtmlEncoder` and `WebUtility.HtmlEncode` are recognized for HTML output, including writer overloads. URL and JavaScript encoding do not clear this finding because they serve different output contexts.

Markdig rendering preserves input taint; `DisableHtml()` alone does not make
Markdown links safe. For stored message content, configure the actual untrusted
property rather than all database strings. See [stored HTML and Markdown](../stored-html.md).

This rule reports a candidate that needs review in the application's trust context. Configure severity with `dotnet_diagnostic.DNA0003.severity` in `.editorconfig`.

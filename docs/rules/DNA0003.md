# DNA0003: Cross-site scripting

CWE-79. Untrusted content reaches raw HTML or markup output and may execute in a user's browser.

**Fix:** Keep Razor/Blazor's normal text encoding. For intentional HTML, use an HTML sanitizer before raw rendering. Encode plain text for its output context.

**Scope:** Includes raw HTML helpers, Blazor markup and modeled HTTP responses with an explicit HTML, XHTML or SVG content type. Unknown content types are not inferred. Markdig conversion preserves taint; `DisableHtml()` alone does not make Markdown links safe.

See [Razor/Blazor](../razor-blazor-taint.md) and [stored HTML/Markdown](../stored-html.md).

# DNA0014: ECB mode use

CWE-327. ECB encryption reveals repeated plaintext blocks.

**Fix:** Use authenticated encryption such as `AesGcm` for new data. Review whether a mode setting is needed solely to decrypt legacy data.

**Scope:** Reports .NET `CipherMode.ECB` assignments and `EncryptEcb`, literal Bouncy Castle ECB selections, and Godot AES ECB encryption. A mode assignment or cipher selection does not prove encryption occurs.

# DNA0002: OS command injection

CWE-78. Untrusted data reaches an executable name or command-line argument. It may select an unintended program or change the command's behavior.

**Fix:** Use a fixed executable and validate arguments for that program. Prefer `ProcessStartInfo.ArgumentList` over constructing an `Arguments` string. Passing untrusted script text to a shell remains unsafe.

**Scope:** `ArgumentList` is not an injection sink in this rule. Review the launched program and argument meaning; a finding does not establish shell execution.

# DNA0003: Cross-site scripting

Rendering untrusted content as HTML allows it to become part of the page rather than ordinary text. An attacker may be able to execute script in another user's browser, read data available to the page or act through that user's session.

## Recommendation

Keep Razor and Blazor's normal text encoding. Use raw HTML rendering only when the content is trusted or has passed through an HTML sanitizer appropriate to the allowed markup. Encoding plain text and sanitizing intentional HTML solve different problems.

Markdown conversion is not HTML sanitization. Markdig output remains untrusted, and disabling raw HTML alone does not establish that links are safe.

## Example

This Razor expression bypasses normal encoding:

```cshtml
@Html.Raw(Model.Comment)
```

If the comment is plain text, render it normally:

```cshtml
@Model.Comment
```

The rule covers supported raw-rendering APIs and HTTP response helpers with an explicit HTML, XHTML or SVG content type. It does not infer unknown content types.

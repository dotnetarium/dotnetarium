# DNA0001: SQL injection

CWE-89. Untrusted data reaches SQL command text and may change the query.

**Fix:** Use database parameters for values. Select table names, column names and other SQL identifiers from a fixed allowlist.

**Scope:** Modeled SQL APIs include Dapper, Npgsql, SqlClient, MySQL, SQLite and EF Core raw SQL. Parameter values are not SQL-text sinks.

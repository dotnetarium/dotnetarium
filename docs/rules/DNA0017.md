# DNA0017: Hardcoded post-quantum private key

CWE-321. Literal private-key material is imported through a .NET 10 `MLKem`, `MLDsa` or `SlhDsa` API.

**Fix:** Generate private keys securely and load persisted keys from protected storage. Replace keys that may have been exposed.

**Scope:** Includes modeled private-key imports and literal PEM private keys passed to these APIs. Public-key imports and key generation are excluded. This rule does not assess PQC algorithm strength or runtime-supplied key material.

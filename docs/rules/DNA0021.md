# DNA0021: XML external entity resolution

An XML document can declare external entities that refer to local files or network resources. If an application parses an untrusted document with unrestricted external resolution enabled, the parser may access those resources with the application's permissions.

## Recommendation

Reject DTDs when the application does not need them and leave the resolver unset or null. If external resources are required, use a resolver restricted to the resources the application actually needs.

## Example

These settings prevent DTD processing and external resource resolution:

```csharp
var settings = new XmlReaderSettings {
    DtdProcessing = DtdProcessing.Prohibit,
    XmlResolver = null
};
using var reader = XmlReader.Create(new StringReader(xml), settings);
```

The rule requires untrusted XML and an explicitly unrestricted `XmlUrlResolver`; reader models also require `DtdProcessing.Parse`. Modern defaults and ambiguous parser settings are not reported. Entity-expansion denial of service is a separate issue and is not covered by this diagnostic.

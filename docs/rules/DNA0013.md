# DNA0013: Legacy cipher use

CWE-327. DES, TripleDES or RC2 is selected through a modeled .NET or Bouncy Castle API.

**Fix:** Use authenticated encryption such as `AesGcm` for new data. If the operation only decrypts legacy data, document that use and suppress it narrowly.

**Scope:** Reports cipher creation or literal algorithm selection, not proof of encryption. CBC alone is not reported. Runtime algorithm names are not inferred.

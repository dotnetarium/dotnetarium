# DNA0013: Legacy cipher use

DES, TripleDES and RC2 are unsuitable choices for new encryption. Their limitations can leave protected data vulnerable even when the surrounding code uses the cryptographic API correctly.

Creating one of these ciphers is not proof that new data is being encrypted. Applications may still need to decrypt existing records or exchange a legacy format during migration.

## Recommendation

Use a supported authenticated encryption scheme, such as AES-GCM, for new data. Plan migration of stored ciphertext rather than continuing to create new legacy ciphertext. Changing an algorithm name alone is not a compatible migration: the format must carry the information required for decryption and authentication.

If the reported operation exists only to decrypt legacy data, document that purpose and suppress that location narrowly.

The rule recognizes supported .NET and Bouncy Castle cipher creation and literal algorithm selections. It does not infer algorithms selected by runtime strings. CBC alone is not reported by this rule.

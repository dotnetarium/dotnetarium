# DNA0010: Insecure cookie configuration

Authentication and session cookies need protection against disclosure. Disabling `HttpOnly` makes a cookie accessible to page scripts; disabling secure transport can allow it to be sent over HTTP. Cross-site cookies also require the `Secure` attribute when `SameSite=None` is used, or modern browsers may reject them.

## Recommendation

Keep authentication and session cookies `HttpOnly` and require secure transport. Choose `SameSite` according to the application's cross-site behavior. `None` can be necessary for some integrations, but it must be paired with a secure cookie.

## Example

For an authentication cookie that does not require cross-site delivery:

```csharp
options.Cookie.HttpOnly = true;
options.Cookie.SecurePolicy = CookieSecurePolicy.Always;
options.Cookie.SameSite = SameSiteMode.Lax;
```

The rule checks explicit unsafe authentication/session settings. For inline custom cookies, it only checks `SameSite=None` without `Secure=true`; it does not assume every custom cookie contains sensitive data. This diagnostic does not establish a CSRF vulnerability.

# DNA0023: Unsafe BinaryFormatter deserialization

**CWE-502.** Reports untrusted data reaching `BinaryFormatter.Deserialize` when
the compilation explicitly references the unsupported
`System.Runtime.Serialization.Formatters` compatibility package from NuGet.

The in-box .NET 10 implementation throws; this package restores the legacy
implementation. Enabling the old project flag alone is not evidence that
deserialization works. Unverified vendored DLLs are outside this narrow scope.

Replace the serializer with `System.Text.Json` and a fixed application DTO schema.
Do not deserialize attacker-controlled formatter data. Serialization binders are
not a safe replacement for migrating away from BinaryFormatter.

The rule follows modeled byte/stream provenance, including remote request data
and proven server-side Blazor events. It does not warn on a fixed payload merely
because the API name appears. No deserialization is executed during scanning.

See the [official migration guide](https://learn.microsoft.com/en-us/dotnet/standard/serialization/binaryformatter-migration-guide).

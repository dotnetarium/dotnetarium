# DNA0005: Open redirect

CWE-601. Untrusted data reaches a redirect target in MVC, Razor Pages, an HTTP response, a Minimal API `Results.Redirect`/`TypedResults.Redirect`, or `AuthenticationProperties.RedirectUri` used to store an authentication return destination. Prefer `LocalRedirect` when only local destinations are allowed. An `IsLocalUrl` call establishes safety only when its result guards the same unchanged value.

Fixed local destinations such as `/Login?ReturnUrl=` and complete literal HTTP(S) origins followed by a path are recognized. A single `/`, a protocol-relative URL, or encoding an otherwise arbitrary destination does not establish a fixed destination. Authentication return URLs are checked when assigned, without requiring the engine to reconstruct a later external-provider callback.

For examples and limits, see [validation precision](../taint-validation.md).

This rule reports a candidate that needs review in the application's trust context. Configure severity with `dotnet_diagnostic.DNA0005.severity` in `.editorconfig`.

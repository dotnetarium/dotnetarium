# DNA0006: LDAP injection

LDAP filters and distinguished names contain characters with special meanings. Inserting user input without the correct escaping can change a directory search or select a different directory object. The consequences depend on the operation and the directory account's permissions.

## Recommendation

Use an LDAP library's context-specific escaping or construction APIs. Filter values and distinguished-name components require different escaping rules; an encoder for one must not be used for the other.

Where the application only needs a small set of searches or destinations, map accepted input to fixed expressions instead of accepting LDAP syntax. SQL, HTML and URL encoding are not substitutes for LDAP escaping.

For example, a filter built as `"(uid=" + userName + ")"` lets special characters in `userName` become part of the filter. Escape the value as an LDAP filter value before placing it inside that expression.

This rule covers both filter and distinguished-name sinks. Review the reported API to choose the appropriate mitigation.

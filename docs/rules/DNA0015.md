# DNA0015: Fixed encryption IV or nonce

CWE-329. Encryption uses a literal or zero-filled IV/nonce. Reusing an AEAD nonce with the same key can compromise confidentiality and integrity.

**Fix:** Use an unpredictable IV for CBC and a nonce unique to each encryption under the same key for AEAD. Store the IV/nonce with the ciphertext.

**Scope:** Covers selected .NET, Bouncy Castle, NSec, Sodium and Godot encryption APIs, including simple unchanged local values. Decryption is excluded. The rule does not prove reuse across separate calls, fields or processes.

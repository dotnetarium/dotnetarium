# DNA0022: Hard-coded network credentials

CWE-798. A configuration file contains a recognizable provider token or authentication key. Anyone with access to the file may obtain the credential.

**Fix:** Remove the credential, retrieve it from a secret store at deployment, and rotate/revoke it if exposed. Use obvious placeholders for test fixtures.

**Scope:** Covers selected GitHub, AWS, Azure, Google Cloud and infrastructure credential formats. Public identifiers are excluded. Detection is offline by default; a format match does not prove the credential is active. Unlike [DNA0009](DNA0009.md), no C# API usage is required.

See [supported credentials, file scope and optional verification](../credential-scanning.md).
